Algorithm Logic

Select an algorithm to begin.

Depth-First Search (DFS)

DFS explores deeply before backtracking. It goes as far down a path as possible before returning to explore other paths.

Key Trait: Memory efficient, but not optimal. Can find long, winding paths.

Breadth-First Search (BFS)

BFS explores level-by-level. It expands all nodes at the current depth before moving to the next level.

Key Trait: Always finds the shortest path (optimal), but uses more memory.

A* Search

A heuristic-based intelligent search that combines the cost to reach a state and the estimated cost to the goal.

f(n) = g(n) + h(n)

Smarter exploration, finding the optimal path quickly.

Algorithm Comparison

DFS

  • Optimality: No
  • Speed: Variable
  • Memory: Low (O(bm))
  • Style: Deep dive & backtrack

BFS

  • Optimality: Yes
  • Speed: Fast for shallow goals
  • Memory: High (O(b^d))
  • Style: Expanding ripples

A* Search

  • Optimality: Yes
  • Speed: Generally Fastest
  • Memory: Medium
  • Style: Goal-directed
